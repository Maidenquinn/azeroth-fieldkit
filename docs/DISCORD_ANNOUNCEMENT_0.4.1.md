# Discord announcement — 0.4.1 draft (EN)

Manual posting only, **after** the GitHub release exists. Do not use a release link before v0.4.1 is published.

```md
**Azeroth FieldKit 0.4.1 — Chat customization & HUD fixes**

This update focuses on the game's native chat and smoother interface customization.

**What's new**
- Move the native chat anywhere on screen, lock/reset its position, and keep it after /reload.
- Adjust chat width, height, visible history, font, text size, background color and opacity.
- Optional custom text colors, or keep the original channel colors.
- Copy chat locally using the shortcut next to the chat window. Nothing is uploaded.
- Fixed chat messages disappearing when changing layout or font settings.
- Fixed the grouped Mode / Damage / Lairs windows getting stuck to the cursor, including when dragging from the Mode panel itself.
- French and English UI improvements.

**Note:** Existing chat lines can only be recolored when FieldKit can safely recover their full contents. Older untracked messages are deliberately left alone.

**Install:** download AzerothFieldKit-0.4.1.zip from the release Assets, replace the addon folder and restart the game. Your settings are preserved; back up SavedVariables first.

Maintained derivative of MASH by Malk.

**Release:** https://github.com/Maidenquinn/azeroth-fieldkit/releases/tag/v0.4.1
```
